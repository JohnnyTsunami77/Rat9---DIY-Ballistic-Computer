# Rat9---DIY-Ballistic-Computer
The RAT9 will be a Weapon Mounted Ballistic Computer similar to the Vortex Impact 4000.  There are two visions for this project.  The original vision is a ballistic computer.  An alternate vision we have been discussing is creating an all encompassing device that includes a laser aiming module similar to the RAPTAR S.  

Main Concerns at the moment are with programming and 3d modeling.  If you have special experience in those fields please reach out to the creators.

The project is currently in the nascent stages.
